## Beschrijving

Mijn website bestaat uit een interactieve kaart van het bloemenveld bij Frankendael. 
Bezoekers kunnen op verschillende zones klikken — zoals de voedseleilanden, heuvels, 
sierlinten en het waterplantgebied — om meer informatie over dat gebied te zien.

**Opvallende features:**

- Interactieve kaart van het bloemenveld (in ontwikkelinhg)
- Uitklapbare zone-informatie 
- Zoekbalk (in ontwikkeling)
